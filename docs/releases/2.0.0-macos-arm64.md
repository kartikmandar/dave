# DAVE 2.0.0 — macOS Apple Silicon

DAVE provides a desktop workflow for astronomical timing analysis: event import,
light curves, averaged power density spectra, data export and workspace save/reopen.

This standalone build bundles Python and its scientific dependencies inside the
app. A separate Python, Pixi or Node installation is not required. It is signed
with the Developer ID of Kartik Mandar, notarized by Apple and supplied with a
stapled notarization ticket. The existing controls, layout and analysis workflows
are preserved. With the owner's authorization, the DAVE branding font is now
Oxanium SemiBold, bundled locally with its SIL Open Font License. Branding size,
placement and colors are retained.

This release includes numeric input and GTI handling fixes, CSV export corrections,
workspace regression coverage and a backend restricted to localhost. Original
Apache-2.0 DAVE logging and image-export components replace the former vendor
Logger.js and Canvas2Image. Existing panel styling, controls and menu choices
are retained. PNG/PDF exports use the bundled Plotly renderer and are tested for
actual plotted content, including PDF page placement.

## Download and install

1. Download `DAVE-2.0.0-macOS-arm64.zip` and `SHA256SUMS` from this release.
2. With both files in the same folder, verify the download with
   `shasum -a 256 -c SHA256SUMS`.
3. Extract the ZIP, move `DAVE.app` to Applications, and open it through Finder.

This build targets Apple Silicon. It was validated on macOS 27.2; Intel and older
macOS versions have not yet been validated. Updates currently require downloading
a new release.

## Validation

Apple accepted notarization submission `2752730b-1768-4dbe-97fe-564707c6003d`
with no issues. The app's stapled ticket validates, and Gatekeeper accepts it as
Notarized Developer ID. The app extracted from the final ZIP passed native
signature, ticket and Gatekeeper verification.

A read-only extraction outside the checkout passed import, light curve creation,
averaged PDS, CSV export and fresh-process workspace reopen against an independent
Stingray reference, with checkout and Homebrew reads denied. Log controls and
real PNG/PDF content also passed. Its application code fingerprint matches the
signed candidate from before notarization: eeeb5e4bcfac8456317be12c7eec57b1a27de608.

## Draft pre-publication materials

The ZIP includes THIRD_PARTY_NOTICES alongside DAVE.app. The app was rebuilt,
signed and notarized after the authorized font and browser component replacements.
Keep the notices with the distribution.
DAVE-2.0.0-RUNTIME-SOURCES.tar.gz supplies verified runtime source archives and
conda recipes/patches; DAVE-2.0.0-CLEAN-MAC-TEST.zip supplies the standalone
acceptance fixture, direct-Stingray references and stock-macOS checks.
ASSET_SHA256SUMS covers all three downloadable archives; SHA256SUMS covers the app
ZIP alone for the installation command above.

This release remains a draft. Logger.js and legacy Canvas2Image have been removed
and replaced with original Apache-2.0 DAVE components; the notice inventory records
no unresolved asset grants. Archangelsk has been replaced with licensed Oxanium.
Runtime-source completeness, LGPL obligations and legacy vendored-browser advisory
disposition require final review. A separate clean-Mac browser-download, offline
Finder-launch and full scientific/workspace acceptance test is prepared but not yet performed. The
authorized branding font and version-stamp changes retain the existing layout,
controls and scientific workflows.
